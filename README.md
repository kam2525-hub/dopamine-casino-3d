# 『3Dドパミン・カジノ (Dopamine Casino 3D)』

3Dのサイバーネオン空間を自由に歩き回り、カジノフロア内に配置された様々な台（スロット、ルーレット、クラッシュ、ATM、PvPオンライン対戦）に近づいてプレイできるバーチャルカジノゲームです。

## 🎮 操作方法
- **WASDキー**: 3Dフロアを移動
- **マウスドラッグ**: 視点回転
- **[E] キー / 画面タップ**: 近づいたカジノ台をプレイ

## 🎰 収録されているゲーム台
1. **MEGA SLOTS (スロットマシン)**: 777で50倍ジャックポット
2. **NEON ROULETTE (ルーレット)**: 赤・黒・緑0にチップを賭けて回転
3. **CRASH ROCKET (クラッシュ・チキンレース)**: 上昇する倍率を見極めて爆発前に利確
4. **PVP VIP ARENA (オンライン対戦)**: PeerJSを使ってURL/ID共有で友達とチップを賭けてダイス対決
5. **ATM (無料補給)**: チップが減ったら無制限に補充可能
